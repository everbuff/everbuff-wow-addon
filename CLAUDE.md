# everbuff.gg working agreement

This repository follows the shared operating manual in `everbuff/everbuff-claude`. Clone it alongside this
repository if it is missing: `git clone git@github.com:everbuff/everbuff-claude.git ../everbuff-claude`

@../everbuff-claude/CLAUDE.md

Rules that apply even if the import above is unavailable: approvals and tasks are GitHub issues in the
repository they belong to, with the full proposal in the issue body and the founder's reply as the record;
nothing gated is built before its issue is closed; no Co-Authored-By or Claude trailers in commits; no em
dashes; verify before claiming anything is fixed; the brand is `everbuff.gg`, lowercase.
